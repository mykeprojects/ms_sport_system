HU-GC-10 – Gestionar métodos de pago
Historia de usuario:
Como aficionado, quiero gestionar mis métodos de pago, para disponer de diferentes 
opciones al momento de realizar operaciones dentro de la plataforma.
Criterios de aceptación:
- El aficionado debe estar previamente registrado en el sistema.
- El sistema debe permitir registrar uno o varios métodos de pago para un 
aficionado.
- Cada método de pago debe quedar asociado con el aficionado correspondiente.
- El sistema debe permitir consultar los métodos de pago registrados por el 
aficionado.
- Se debe permitir actualizar la información de un método de pago cuando 
corresponda.
- Se debe permitir eliminar o desactivar un método de pago cuando no existan 
restricciones que lo impidan.
- El sistema debe validar los datos obligatorios según el tipo de método de pago 
registrado.
- No se debe permitir utilizar un método de pago que no pertenezca al aficionado.
- La eliminación de un método de pago no debe eliminar las operaciones realizadas 
previamente con dicho método.
- Los cambios realizados deben quedar almacenados correctamente.
