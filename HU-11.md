HU-GC-11 – Gestionar apuestas sobre partidos
Historia de usuario:
Como aficionado, quiero realizar apuestas sobre los partidos disponibles utilizando uno de
mis métodos de pago y consultar posteriormente su liquidación, para conocer el resultado
de mi apuesta y el valor correspondiente en caso de resultar ganadora.
Criterios de aceptación:
- El aficionado debe estar previamente registrado en el sistema.
- El partido debe estar previamente registrado y habilitado para recibir apuestas.
- El sistema debe permitir consultar los partidos disponibles para apostar.
- El aficionado debe poder seleccionar el partido sobre el cual desea realizar la 
apuesta.
- El sistema debe permitir registrar la selección realizada, el valor apostado y la 
cuota correspondiente.
- La apuesta debe quedar asociada con el aficionado y el partido seleccionados.
- El aficionado debe seleccionar uno de sus métodos de pago registrados para 
realizar la apuesta.
- No se debe permitir utilizar un método de pago perteneciente a otro aficionado.
- El sistema debe validar que el valor de la apuesta cumpla con las condiciones 
establecidas.
- No se deben permitir nuevas apuestas cuando el partido haya iniciado o cuando las
apuestas se encuentren cerradas.
- La cuota de la apuesta debe quedar almacenada al momento de realizarla y no 
debe modificarse posteriormente.
- El aficionado debe poder consultar las apuestas realizadas y el estado de cada una.
- El administrador deportivo debe poder consultar las apuestas realizadas sobre un 
partido. Una apuesta registrada no debe poder modificarse después de que el partido haya 
iniciado.
- La cancelación de una apuesta solo debe permitirse cuando las reglas establecidas 
lo permitan.
- La apuesta solo debe poder liquidarse cuando el partido haya finalizado y tenga un 
resultado oficial registrado.
- Al finalizar el partido, el sistema debe comparar la selección realizada por el 
aficionado con el resultado oficial.
- Si la selección coincide con el resultado correspondiente, la apuesta debe quedar 
en estado ganada.
- Si la selección no coincide con el resultado correspondiente, la apuesta debe 
quedar en estado perdida.
- Si el partido es cancelado o se presenta una condición que invalide la apuesta, esta
debe quedar en estado anulada, según las reglas establecidas.
- Para una apuesta ganadora, el sistema debe calcular el valor a pagar mediante la 
fórmula: valor apostado × cuota.
- Para una apuesta perdida, el valor a pagar debe ser cero.
- Para una apuesta anulada, se debe devolver al aficionado el valor originalmente 
apostado.
- La liquidación debe realizarse utilizando la cuota registrada al momento de realizar
la apuesta.
- Una misma apuesta no debe poder liquidarse más de una vez.
- Una vez liquidada, el sistema debe almacenar el estado final y el valor pagado o 
devuelto.
- El aficionado debe poder consultar el resultado y la liquidación de sus apuestas.
- El sistema debe notificar al aficionado cuando una apuesta sea registrada y cuando
sea liquidada.
